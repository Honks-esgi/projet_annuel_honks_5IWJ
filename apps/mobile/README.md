# Mobile Honks (React Native)

Ce dossier contiendra l'application mobile du projet Honks.

## Responsabilites

- Selection d'un jeu et creation d'une demande de session
- Envoi de notifications push aux amis
- Reponse rapide: Honk back / No Honk
- Gestion des invitations en cours de session
- Support potentiel audio/WebRTC via react-native-webrtc (bonus)

## Stack cible

- React Native
- Socket.io client
- react-native-webrtc
- Jest (tests)

## Notes

- Aucun code n'est initialise pour l'instant.
- L'implementation sera ajoutee dans les prochaines etapes du projet.
