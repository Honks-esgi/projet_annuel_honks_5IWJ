# API Honks (NestJS)

Ce dossier contiendra l'API backend du projet Honks.

## Responsabilites

- Exposer les endpoints REST metier
- Gerer les flux temps reel via WebSockets (Socket.io)
- Piloter le signaling WebRTC
- Integrer l'authentification deleguee via Autentik
- Orchestrer la logique de sessions, invitations, honk back / no honk

## Stack cible

- NestJS
- PostgreSQL
- Socket.io
- Jest (tests unitaires et integration)
